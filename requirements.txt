# Focus Guard — pinned dependencies
#
#   VM (Ubuntu + Blackwell GPU)  -> training      uv pip install -r requirements.txt
#   Mac (M-series)               -> app + inference
#
# Python 3.11 on both machines.
#
# WHY TORCH ON THE VM AND TENSORFLOW ON THE MAC
# The VM's GPU reports compute capability 12.0 (sm_120, Blackwell), which needs
# CUDA 12.8 or newer. TensorFlow 2.15 ships CUDA 12.2 / cuDNN 8.9, and even the
# latest TF 2.21 ships 12.5 / 9.3 — so no stable TensorFlow wheel has kernels for
# this card. It detects the GPU and then fails at the first convolution, because
# cuDNN is a closed binary that cannot JIT from PTX. PyTorch 2.7+ cu128 was the
# first stable release with native sm_120 support.
#
# So: the VM trains in PyTorch and exports ONNX; the Mac runs that ONNX in the
# webcam app. TensorFlow stays on the Mac only, for the existing .h5 baseline.

--extra-index-url https://download.pytorch.org/whl/cu128
